# 投稿ルール ナレッジファイル（V2）

> 対象ジャンル: スキンケア成分知識
> 形式: テキストのみ（画像なし）/ 500文字以内
> 投稿上限: 6件/日
> 品質閾値: 7.5以上（2群平均方式）
> 最終更新: 2026-03-28

---

## 1. 投稿パターン 9種 + スレッド形式 定義

### 配分

- **拡散系 60%:** コメント誘導型、反常識型、短文完結型、二択比較型、あるある共感型
- **保存系 40%:** リスト系、まとめ結論先出型、タイムライン型、数字インパクト型
- **スレッド形式 40%:** 上記パターンとは別枠で、全投稿の40%をツリー展開型（スレッド形式）にする

### ローテーションルール

- 直近3件で使ったパターンはブロック
- post_queue内の未投稿分も考慮
- 選択可能パターン = 全9パターン - 使用済みパターン
- スレッド比率は直近20件+pending queueから算出し、不足時に自動ブースト

### パターン詳細

#### パターン1: コメント誘導型【拡散系】

**構成:**
```
[フック（1行目）]
[本文2〜4行: 成分知識の提示]
[問いかけ（最終行）]
```

**例:**
```
ナイアシンアミドが入ってればOKって思ってない？
実は濃度によって全然違う。

成分表の何番目に書いてあるか見てみて。
上の方にあったら合格。

みんなは成分表のどこまで見てる？
```

---

#### パターン2: 反常識型【拡散系】

**構成:**
```
[通説の否定（1行目）]
[なぜ間違いなのか（2〜3行）]
[正しいアプローチ（1〜2行）]
[シグネチャー語尾]
```

**例:**
```
「無添加」って書いてあるだけで安心してない？

日本には「無添加」の法的な定義がない。
パラベン無添加でも、別の防腐剤は入ってる。

大事なのは「何が無添加なのか」を確認すること。

成分表は嘘つかない。
```

---

#### パターン3: 短文完結型【拡散系】

**構成:**
```
[フック（1行目）]
[核心となる主張/気づき（1〜2文）]
```

**例:**
```
今使ってる化粧水、裏返してみて。
成分表の3行目以内にセラミドNPがあったら
それ、かなり良いやつだよ。
```

---

#### パターン4: 二択比較型【拡散系】

**構成:**
```
[AとBの比較提示（1行目）]
[Aの特徴（1〜2行）]
[Bの特徴（1〜2行）]
[判断基準の提示]
```

**例:**
```
高分子ヒアルロン酸 vs 低分子ヒアルロン酸
結局どっちがいいのか問題。

高分子: 肌の表面でフタをする◎ しっとり感◎
低分子: 角質層まで届きやすい◎ さっぱり◎

乾燥が気になるなら高分子、べたつきが嫌なら低分子。
成分表で見分けてみて。
```

---

#### パターン5: あるある共感型【拡散系】

**構成:**
```
[「〇〇な人」の提示（1行目）]
[あるあるエピソード（2〜4行）]
[成分知識による解決策 or 気づき（1行）]
```

**例:**
```
「化粧水めっちゃ塗ってるのに乾燥する」って人、
絶対いるよね。

それ、水分は足りてるけど
フタをする油分が足りてないかもしれない。

成分表にセラミドかスクワランが入ってるか
チェックしてみて。
```

---

#### パターン6: リスト系【保存系】

**構成:**
```
[フック（1行目）]

・項目1
・項目2
・項目3
（3〜7項目）

[シグネチャー語尾]
```

**例:**
```
敏感肌が避けたほうがいいかもしれない成分3つ

・高濃度エタノール（成分表の上位にある場合）
・合成香料（「香料」表記のもの）
・高濃度レチノール（A反応のリスクあり）

当てはまるものがあったら裏面チェックしてみて。

知ってるだけで変わる。
```

---

#### パターン7: まとめ結論先出型【保存系】

**構成:**
```
[結論（1行目）]
[理由1（1〜2行）]
[理由2（1〜2行）]
[行動提案（1行）]
```

**例:**
```
成分表で一番大事なのは「最初の5つ」。

理由①: 配合量1%以上の成分は多い順に並んでる
理由②: 6番目以降は微量配合の可能性が高い

まずは最初の5つだけ読む癖をつけてみて。

これ、覚えておいて。
```

---

#### パターン8: タイムライン型【保存系】

**構成:**
```
[フック（1行目）]

朝: ○○
夜: ○○

[補足（1行）]
```

**例:**
```
乾燥肌のスキンケア、朝と夜で変えたほうがいい理由

朝: 軽めの保湿 → 日焼け止め（水→油の順）
夜: クレンジング → 化粧水 → セラミド系クリーム

夜に油分多めのクリームでフタをするのがポイント。
```

---

#### パターン9: 数字インパクト型【保存系】

**構成:**
```
[具体的な数字を含む1行目]
[数字の裏にある背景や解説（2〜3行）]
[行動促進（1〜2行）]
```

**例:**
```
角質層の細胞間脂質の約50%がセラミド。

つまりバリア機能の半分を
セラミドが担ってるってこと。

セラミド入りの化粧品を選ぶ理由、
これだけで十分だと思う。
```

---

#### ツリー展開型（スレッド形式）【保存系/拡散系】

**構成（2〜3ポストの自己リプライ連結）:**
```
[1ポスト目: フック + 導入（読者のスクロールを止める）]
↓ 自己リプライ
[2ポスト目: 本題の解説（具体的な成分知識・手順・根拠）]
↓ 自己リプライ（3ポスト構成の場合）
[3ポスト目: まとめ + シグネチャー語尾]
```

**例（2ポスト）:**
```
[1ポスト目]
「セラミド入り」って書いてあるだけで
選んでない？

実はセラミドにも種類がある。
成分表のどこを見ればいいか、次のポストで。

[2ポスト目]
成分表に「セラミドNP」「セラミドAP」「セラミドEOP」
って書いてあったら当たり。

逆に「セラミド」としか書いてないやつは
疑似セラミドの可能性がある。

裏面チェックしてみて。
成分表は嘘つかない。
```

**使いどころ:** 全投稿の40%目標。成分解説やルーティンなど情報量が多いテーマ。

**制約:**
- 各ポスト500文字以内
- 1ポスト目は必ずフックで始める
- 最終ポストにシグネチャー語尾を推奨
- 最大3ポストまで（長すぎるとスクロール離脱）

---

#### パターン17: 質問募集型【拡散系】

**構成:**
```
[フック（1行目）: スキンケアの悩みに触れる]
[本文2〜3行: テーマの提示や最近気になること]
[質問募集CTA（最終行）: 「コメントで教えて」「気になること聞いて」等]
```

**例:**
```
最近よく聞かれるスキンケアの質問、
まとめて答えようかなと思ってて。

みんなが気になってること、
コメントで教えてくれたらうれしい。

成分のこと、使い方、なんでもOKだよ
```

**使いどころ:** 週2回。コメント数増加によるエンゲージメント向上狙い。

**禁止事項:**
- 質問テーマが限定的すぎる（広くフォロワーが参加できるように）
- 連日の質問募集（間隔を空ける）

---

#### パターン18: フォロワー質問回答型【保存系/拡散系】

**構成:**
```
[質問への共感/引用（1行目）: 「〇〇って質問もらった」等]
[回答本文（3〜5行）: 具体的な成分知識・根拠]
[シグネチャー語尾 or フォローアップの問いかけ]
```

**例:**
```
「化粧水と乳液の順番って本当に大事？」
って質問もらったんだけど、結論から言うと大事。

化粧水→乳液の順番は「水→油」の原則。
逆にすると油膜が邪魔して水分が入りにくい。

ただし、導入美容液を使うなら
洗顔→導入→化粧水→乳液の順番ね。

知ってるだけで変わる。
```

**使いどころ:** フォロワー質問がresearch_poolにある時に自動選択。

**禁止事項:**
- 質問者のユーザー名を投稿本文に含めない
- 医療的判断を求める質問には「専門家に相談してね」と添える
- 薬機法違反表現（「治る」「効く」等）

## 2. 文体ルール

### 基本ルール
- 1文40文字以内
- 漢字率30%以下（ひらがな多めで柔らかく）
- 改行は2〜3文ごとに空行
- 絵文字は1投稿に0〜2個まで
- 「！」は1投稿に最大1個
- 一人称は使わない or 最小限
- 製品名・ブランド名は一切出さない
- 投稿の締めにシグネチャー語尾を推奨

### シグネチャー語尾
- 「成分表は嘘つかない。」
- 「知ってるだけで変わる。」
- 「これ、覚えておいて。」

### 使える語尾
- 「〜なんだよね」「〜って知ってた？」「〜してみて」
- 「〜かもしれない」「〜だと思う」「〜が正解」

### 使わない語尾
- 「〜でございます」「〜いたします」「〜ですよね！」「いかがでしたか」

## 3. 品質スコア 採点基準（V2: 7項目 × 10点）

### 2群平均方式

```
内容品質群 = avg(有益性, 具体性, 感情移入しやすさ)
表現品質群 = avg(自然さ, テンポ, 体験語り感, 業者臭さのなさ)
最終スコア = avg(内容品質群, 表現品質群)
```

閾値: **7.5未満は自動破棄**

### 3-1. 自然さ（Naturalness）

| 点数 | 基準 |
|------|------|
| 9-10 | 完全に人間が書いたように読める |
| 5-6 | 一部不自然な言い回しがある |
| 1-2 | 明らかにAI生成とわかる |

### 3-2. 有益性（Usefulness）

| 点数 | 基準 |
|------|------|
| 9-10 | 読者が今日から行動を変えられる |
| 5-6 | 参考にはなるが具体性に欠ける |
| 1-2 | 当たり前のことしか言っていない |

### 3-3. 具体性（Specificity）

| 点数 | 基準 |
|------|------|
| 9-10 | 成分名+濃度+条件が明示 |
| 5-6 | 成分名はあるが条件が曖昧 |
| 1-2 | 「良い成分」のような抽象表現のみ |

### 3-4. 感情移入しやすさ（Empathy）

| 点数 | 基準 |
|------|------|
| 9-10 | 「わかる！」と声に出るレベル |
| 5-6 | 理解はできるが共感まで届かない |
| 1-2 | 教科書的で感情が動かない |

### 3-5. テンポ（Tempo）

| 点数 | 基準 |
|------|------|
| 9-10 | スクロールの手が止まり最後まで読む |
| 5-6 | 普通に読める |
| 1-2 | 文が長く途中で離脱する |

### 3-6. 体験語り感（Experiential）

| 点数 | 基準 |
|------|------|
| 9-10 | 「この人、実際に試したんだな」と感じる |
| 5-6 | 知識としては正しいが体験感が薄い |
| 1-2 | 完全に教科書・Wikipedia調 |

### 3-7. 業者臭さのなさ（Non-commercial）

| 点数 | 基準 |
|------|------|
| 9-10 | 友達の話を聞いている感覚 |
| 5-6 | やや「おすすめ」感が出ている |
| 1-2 | 明らかにステマ・まとめサイト調 |

## 4. NGワード・NG表現

### 即ブロック（Level 1）
- 薬機法違反表現: 「効く」「治る」「浸透する」等
- 景表法違反表現: 「No.1」「最安値」「100%の人が」等
- 詳細は `config/ng_words.txt` 参照

### 警告（Level 2）
- グレーゾーン表現: 「コスパ最強」「断トツ」「ハズレ」等
- ブランド名・製品名の言及 → `config/brand_names.txt` 参照

### bot臭い表現（Level 3）
- 「いかがでしたか」「参考になったら」「皆さんこんにちは」等
- AI臭: 「包括的な」「網羅的な」「効果的な」「最適な」の多用
- 「〜することが重要です」「〜が鍵となります」
