# 投稿ルール ナレッジファイル（V2）

> 対象ジャンル: スキンケア成分知識
> 形式: テキストのみ（画像なし）/ 500文字以内
> 投稿上限: 6件/日
> 品質閾値: 7.5以上（2群平均方式）
> 最終更新: 2026-03-28

---

## 1. 投稿パターン 9種 + スレッド形式 定義

### 配分

- **拡散系 60%:** コメント誘導型、反常識型、短文完結型、二択比較型、あるある共感型
- **保存系 40%:** リスト系、まとめ結論先出型、タイムライン型、数字インパクト型
- **スレッド形式 40%:** 上記パターンとは別枠で、全投稿の40%をツリー展開型（スレッド形式）にする

### ローテーションルール

- 直近3件で使ったパターンはブロック
- post_queue内の未投稿分も考慮
- 選択可能パターン = 全9パターン - 使用済みパターン
- スレッド比率は直近20件+pending queueから算出し、不足時に自動ブースト

### パターン詳細

#### パターン1: コメント誘導型【拡散系】

**構成:**
```
[フック（1行目）]
[本文2〜4行: 成分知識の提示]
[問いかけ（最終行）]
```

**例:**
```
ナイアシンアミドが入ってればOKって思ってない？
実は濃度によって全然違う。

成分表の何番目に書いてあるか見てみて。
上の方にあったら合格。

みんなは成分表のどこまで見てる？
```

---

#### パターン2: 反常識型【拡散系】

**構成:**
```
[通説の否定（1行目）]
[なぜ間違いなのか（2〜3行）]
[正しいアプローチ（1〜2行）]
[シグネチャー語尾]
```

**例:**
```
「無添加」って書いてあるだけで安心してない？

日本には「無添加」の法的な定義がない。
パラベン無添加でも、別の防腐剤は入ってる。

大事なのは「何が無添加なのか」を確認すること。

成分表は嘘つかない。
```

---

#### パターン3: 短文完結型【拡散系】

**構成:**
```
[フック（1行目）]
[核心となる主張/気づき（1〜2文）]
```

**例:**
```
今使ってる化粧水、裏返してみて。
成分表の3行目以内にセラミドNPがあったら
それ、かなり良いやつだよ。
```

---

#### パターン4: 二択・比較型【拡散系】

**構成:**
```
[AとBの比較提示（1行目）]
[Aの特徴（1〜2行）]
[Bの特徴（1〜2行）]
[判断基準の提示]
```

**例:**
```
高分子ヒアルロン酸 vs 低分子ヒアルロン酸
結局どっちがいいのか問題。

高分子: 肌の表面でフタをする◎ しっとり感◎
低分子: 角質層まで届きやすい◎ さっぱり◎

乾燥が気になるなら高分子、べたつきが嫌なら低分子。
成分表で見分けてみて。
```

---

#### パターン5: あるある共感型【拡散系】

**構成:**
```
[「〇〇な人」の提示（1行目）]
[あるあるエピソード（2〜4行）]
[成分知識による解決策 or 気づき（1行）]
```

**例:**
```
「化粧水めっちゃ塗ってるのに乾燥する」って人、
絶対いるよね。

それ、水分は足りてるけど
フタをする油分が足りてないかもしれない。

成分表にセラミドかスクワランが入ってるか
チェックしてみて。
```

---

#### パターン6: リスト系【保存系】

**構成:**
```
[フック（1行目）]

・項目1
・項目2
・項目3
（3〜7項目）

[シグネチャー語尾]
```

**例:**
```
敏感肌が避けたほうがいいかもしれない成分3つ

・高濃度エタノール（成分表の上位にある場合）
・合成香料（「香料」表記のもの）
・高濃度レチノール（A反応のリスクあり）

当てはまるものがあったら裏面チェックしてみて。

知ってるだけで変わる。
```

---

#### パターン7: まとめ・結論先出型【保存系】

**構成:**
```
[結論（1行目）]
[理由1（1〜2行）]
[理由2（1〜2行）]
[行動提案（1行）]
```

**例:**
```
成分表で一番大事なのは「最初の5つ」。

理由①: 配合量1%以上の成分は多い順に並んでる
理由②: 6番目以降は微量配合の可能性が高い

まずは最初の5つだけ読む癖をつけてみて。

これ、覚えておいて。
```

---

#### パターン8: タイムライン型【保存系】

**構成:**
```
[フック（1行目）]

朝: ○○
夜: ○○

[補足（1行）]
```

**例:**
```
乾燥肌のスキンケア、朝と夜で変えたほうがいい理由

朝: 軽めの保湿 → 日焼け止め（水→油の順）
夜: クレンジング → 化粧水 → セラミド系クリーム

夜に油分多めのクリームでフタをするのがポイント。
```

---

#### パターン9: 数字インパクト型【保存系】

**構成:**
```
[具体的な数字を含む1行目]
[数字の裏にある背景や解説（2〜3行）]
[行動促進（1〜2行）]
```

**例:**
```
角質層の細胞間脂質の約50%がセラミド。

つまりバリア機能の半分を
セラミドが担ってるってこと。

セラミド入りの化粧品を選ぶ理由、
これだけで十分だと思う。
```

---

#### ツリー展開型（スレッド形式）【保存系/拡散系】

**構成（2〜3ポストの自己リプライ連結）:**
```
[1ポスト目: フック + 導入（読者のスクロールを止める）]
↓ 自己リプライ
[2ポスト目: 本題の解説（具体的な成分知識・手順・根拠）]
↓ 自己リプライ（3ポスト構成の場合）
[3ポスト目: まとめ + シグネチャー語尾]
```

**例（2ポスト）:**
```
[1ポスト目]
「セラミド入り」って書いてあるだけで
選んでない？

実はセラミドにも種類がある。
成分表のどこを見ればいいか、次のポストで。

[2ポスト目]
成分表に「セラミドNP」「セラミドAP」「セラミドEOP」
って書いてあったら当たり。

逆に「セラミド」としか書いてないやつは
疑似セラミドの可能性がある。

裏面チェックしてみて。
成分表は嘘つかない。
```

**使いどころ:** 全投稿の40%目標。成分解説やルーティンなど情報量が多いテーマ。

**制約:**
- 各ポスト500文字以内
- 1ポスト目は必ずフックで始める
- 最終ポストにシグネチャー語尾を推奨
- 最大3ポストまで（長すぎるとスクロール離脱）

#### パターン10: 暴露・裏話系【拡散系】

**コンセプト:** 「実は〇〇だった」という意外性で読者を引き込む。業界の慣習・誤解を優しく暴露するトーン。特定商品・ブランドへの言及は禁止。

**構成:**
```
[1行目: 暴露宣言（「実は〜だった」「知らなかった人へ」）]
[2〜4行: 一般的な誤解の説明]
[5〜7行: 実際はどうなのか（成分・データ付き）]
[末尾: 「知ってた？」でコメント誘導]
```

**例:**
```
「浸透する化粧水」って言葉、
実はあんまり意味ない。

肌の角質層は外部物質の侵入をブロックする構造。
水溶性の化粧水成分がグイグイ入ることはない。

化粧水の役割は「角質を整える」「油分のベースを作る」。
浸透させるものではなく、整えるもの。

知ってた？
```

**文字数:** 150〜250字

---

#### パターン11: 需要確認型【拡散系】

**コンセプト:** 「これ需要ある？」「まとめていい？」でコメント参加を促す。フォロワーとの双方向感を出す。

**構成:**
```
[1行目: テーマの提示（「〇〇についてまとめていい？」）]
[2〜3行: なぜそれが気になるのかの文脈]
[末尾: 参加を促すCTA（「コメントで教えて」「需要ある？」）]
```

**例:**
```
プチプラで本当に効く化粧水、
まとめてほしい人いる？

成分で選ぶとコスパ良くなるの、
知ってもらいたくて。

「まとめて」ってコメントくれたら
ちゃんと作る。
```

**文字数:** 80〜150字

#### パターン12: ビフォーアフター型【保存系】

**コンセプト:** 「〇ヶ月前→今」の変化を具体的数値・成分とともに語る。実体験ベースで共感を呼ぶ。

**構成:**
```
[1行目: 変化の宣言（「〇ヶ月で〜が変わった」）]
[2〜4行: 以前の状態の描写]
[5〜7行: 変えたこと（成分・習慣）]
[末尾: 変化の結果 + 読者への問いかけ]
```

**例:**
```
半年前と今、毛穴の見え方が全然違う。

以前は毎朝ファンデーションを厚塗りしてた。
洗顔後すぐベタつくのに、夕方はカサカサ。

変えたのはナイアシンアミド（5%以上のもの）を
夜のルーティンに加えただけ。

毛穴の目立ちが気になる人、試してみて。
```

**文字数:** 120〜220字

---

#### パターン13: 失敗談型【拡散系】

**コンセプト:** 自分の失敗経験から学んだことを語る。共感＋有益性のセット。「やらかした経験談」は読者の安心感につながる。

**構成:**
```
[1行目: 失敗の告白（「〇〇してた頃、ひどかった」）]
[2〜3行: 何がまずかったか（具体的な行動）]
[4〜5行: 気づいたこと・変えたこと]
[末尾: 同じ人へのメッセージ]
```

**例:**
```
スクラブを毎週やってた頃、肌が荒れまくってた。

物理的な摩擦で角質をゴシゴシ取り除いてたけど
バリア機能を一緒に壊してた。

今はAHAを薄めに使うだけ。摩擦ゼロ。
肌が落ち着いてから毛穴も気にならなくなった。

同じことしてた人いる？
```

**文字数:** 100〜200字

---

#### パターン14: ランキング異議型【拡散系】

**コンセプト:** 「世間の評価に異議あり」でコメント誘発。ランキングや有名商品への異議を、成分観点で語る。感情的な批判NG。成分・成分カテゴリの話に絞る。

**構成:**
```
[1行目: 異議宣言（「〇〇1位のアレ、成分で見ると微妙」）]
[2〜3行: 世間の評価の背景]
[4〜5行: 成分目線での問題点]
[末尾: 「みんなはどう思う？」でコメント誘導]
```

**例:**
```
ランキング上位の化粧水、
成分表で見ると首をかしげるやつがある。

「全成分無添加」が売りなのに
香料（天然）はしっかり入ってる、とか。

天然だから安全とは限らないのに。
みんなどうやって選んでる？
```

**文字数:** 100〜200字
**注意:** 特定ブランド・製品名は出さない。成分・成分カテゴリのみ。

---

#### パターン15: 季節タイムリー型【拡散系/保存系】

**コンセプト:** 季節に合わせた旬の成分・ケアを提案。タイムリーなフックで読まれやすくなる。

**構成:**
```
[1行目: 季節の状況・悩みに言及]
[2〜4行: その季節特有のスキンケア課題]
[5〜7行: 対応する成分・ケア方法]
[末尾: 読者への問いかけ or アクション提案]
```

**例:**
```
花粉シーズン、肌がヒリヒリする人いない？

花粉が飛ぶと肌のバリア機能が落ちやすい。
花粉自体も刺激になるけど、かゆくて触るのが一番まずい。

この時期はセラミド多めのクリームを重ねて
バリア機能を先に補う。洗顔もマイルドに。

もう対策してる人いる？
```

**文字数:** 120〜220字
**使いどころ:** 季節の変わり目・特定イベント（花粉・梅雨・夏・乾燥期）に合わせて使う。

#### パターン16: 実体験レビュー型【拡散系】

**コンセプト:** 成分を実際に試した視点で語る。「この人、本当に使ってる」と感じさせる体験描写が核心。

**構成:**
```
[1行目: 試した動機・状況（「〇〇が気になって試してみた」）]
[2〜4行: 使い始めの感触・変化]
[5〜6行: 成分目線での考察]
[末尾: 率直な評価 + 読者への問いかけ]
```

**例:**
```
レチノールがこわくて敬遠してたけど
ついに試してみた。

最初の2週間は少し乾燥が増えた。
「A反応」って言われるやつ。

でも濃度を0.025%から始めたら
肌荒れはほぼなかった。低濃度スタートが正解だと思う。

試してる人、どのくらいで変化感じた？
```

**文字数:** 120〜220字

---

#### パターン17: 質問募集型【拡散系】

**構成:**
```
[フック（1行目）: スキンケアの悩みに触れる]
[本文2〜3行: テーマの提示や最近気になること]
[質問募集CTA（最終行）: 「コメントで教えて」「気になること聞いて」等]
```

**例:**
```
最近よく聞かれるスキンケアの質問、
まとめて答えようかなと思ってて。

みんなが気になってること、
コメントで教えてくれたらうれしい。

成分のこと、使い方、なんでもOKだよ
```

**使いどころ:** 週2回。コメント数増加によるエンゲージメント向上狙い。

**禁止事項:**
- 質問テーマが限定的すぎる（広くフォロワーが参加できるように）
- 連日の質問募集（間隔を空ける）

---

#### パターン18: フォロワー質問回答型【保存系/拡散系】

**構成:**
```
[質問への共感/引用（1行目）: 「〇〇って質問もらった」等]
[回答本文（3〜5行）: 具体的な成分知識・根拠]
[シグネチャー語尾 or フォローアップの問いかけ]
```

**例:**
```
「化粧水と乳液の順番って本当に大事？」
って質問もらったんだけど、結論から言うと大事。

化粧水→乳液の順番は「水→油」の原則。
逆にすると油膜が邪魔して水分が入りにくい。

ただし、導入美容液を使うなら
洗顔→導入→化粧水→乳液の順番ね。

知ってるだけで変わる。
```

**使いどころ:** フォロワー質問がresearch_poolにある時に自動選択。

**禁止事項:**
- 質問者のユーザー名を投稿本文に含めない
- 医療的判断を求める質問には「専門家に相談してね」と添える
- 薬機法違反表現（「治る」「効く」等）

## 2. 文体ルール

### 基本ルール
- 1文40文字以内
- 漢字率30%以下（ひらがな多めで柔らかく）
- 改行は2〜3文ごとに空行
- 絵文字は1投稿に0〜2個まで
- 「！」は1投稿に最大1個
- 一人称は使わない or 最小限
- 製品名・ブランド名は一切出さない
- 投稿の締めにシグネチャー語尾を推奨

### シグネチャー語尾
- 「成分表は嘘つかない。」
- 「知ってるだけで変わる。」
- 「これ、覚えておいて。」

### 使える語尾
- 「〜なんだよね」「〜って知ってた？」「〜してみて」
- 「〜かもしれない」「〜だと思う」「〜が正解」

### 使わない語尾
- 「〜でございます」「〜いたします」「〜ですよね！」「いかがでしたか」

## 3. 品質スコア 採点基準（V2: 7項目 × 10点）

### 2群平均方式

```
内容品質群 = avg(有益性, 具体性, 感情移入しやすさ)
表現品質群 = avg(自然さ, テンポ, 体験語り感, 業者臭さのなさ)
最終スコア = avg(内容品質群, 表現品質群)
```

閾値: **7.5未満は自動破棄**

### 3-1. 自然さ（Naturalness）

| 点数 | 基準 |
|------|------|
| 9-10 | 完全に人間が書いたように読める |
| 5-6 | 一部不自然な言い回しがある |
| 1-2 | 明らかにAI生成とわかる |

### 3-2. 有益性（Usefulness）

| 点数 | 基準 |
|------|------|
| 9-10 | 読者が今日から行動を変えられる |
| 5-6 | 参考にはなるが具体性に欠ける |
| 1-2 | 当たり前のことしか言っていない |

### 3-3. 具体性（Specificity）

| 点数 | 基準 |
|------|------|
| 9-10 | 成分名+濃度+条件が明示 |
| 5-6 | 成分名はあるが条件が曖昧 |
| 1-2 | 「良い成分」のような抽象表現のみ |

### 3-4. 感情移入しやすさ（Empathy）

| 点数 | 基準 |
|------|------|
| 9-10 | 冒頭1秒で「自分のことだ」と思える。「わかる！」と声に出るレベル |
| 5-6 | 理解はできるが共感まで届かない。冒頭が知識の説明から始まっている |
| 1-2 | 教科書的で感情が動かない。読者の悩みが一切出てこない |

### 3-5. テンポ（Tempo）

| 点数 | 基準 |
|------|------|
| 9-10 | スクロールの手が止まり最後まで読む |
| 5-6 | 普通に読める |
| 1-2 | 文が長く途中で離脱する |

### 3-6. 体験語り感（Experiential）

| 点数 | 基準 |
|------|------|
| 9-10 | 「この人、実際に試したんだな」と感じる |
| 5-6 | 知識としては正しいが体験感が薄い |
| 1-2 | 完全に教科書・Wikipedia調 |

### 3-7. 業者臭さのなさ（Non-commercial）

| 点数 | 基準 |
|------|------|
| 9-10 | 友達の話を聞いている感覚 |
| 5-6 | やや「おすすめ」感が出ている |
| 1-2 | 明らかにステマ・まとめサイト調 |

## 4. NGワード・NG表現

### 即ブロック（Level 1）
- 薬機法違反表現: 「効く」「治る」「浸透する」等
- 景表法違反表現: 「No.1」「最安値」「100%の人が」等
- 詳細は `config/ng_words.txt` 参照

### 警告（Level 2）
- グレーゾーン表現: 「コスパ最強」「断トツ」「ハズレ」等
- ブランド名・製品名の言及 → `config/brand_names.txt` 参照

### bot臭い表現（Level 3）
- 「いかがでしたか」「参考になったら」「皆さんこんにちは」等
- AI臭: 「包括的な」「網羅的な」「効果的な」「最適な」の多用
- 「〜することが重要です」「〜が鍵となります」

## 5. フォロワーが伸びる投稿の原則（toki_sns01参考）

フォロワーが4桁になるために意識すべきチェックリスト。投稿生成・レビュー時に照合する。

### 5-1. 冒頭フックの自己投影テスト

> **「冒頭1秒で読者が自分のことだとイメージできるか？」**

- **◎ 良い例:** 「化粧水めっちゃ塗ってるのに乾燥する」って人
- **✗ 悪い例:** 「セラミドとは〜」「本日は〜について解説します」

→ 1行目は必ず読者の**悩み・状況・行動**から始める。知識の説明から始めない。

### 5-2. ロボット投稿チェック

> **「ノウハウばかりで、ロボットみたいだね」を防ぐ**

- ノウハウ連投は最大2件まで。3件目は共感・体験・ユーモア系を混ぜる
- 「〜を調べた」「〜を試してみた感覚」「〜って思ってたら違ってた」など**一人称の体験感**を差し込む
- 教科書的な定義から入らない。成分を「語る」のではなく「一緒に見る」スタンス

### 5-3. ライフスタイル提示

> **「この発信を見るとどんな生活が実現できるか」を意識する**

- 成分知識を学ぶと**何が変わるか**をたまに明示する
  - 例：「成分表が読めると、ドラッグストアで迷わなくなる」
  - 例：「5分でスキンケアを選べるようになる」
- 毎投稿に入れる必要はない。月に2〜3本の「未来提示型」投稿を入れる

### 5-4. 専門用語の噛み砕き

> **「専門用語が多くて何をいっているか分からない」を防ぐ**

- 初出の成分名には必ず**1行で役割を添える**
  - 例：「ナイアシンアミド（シミを抑える成分）」
  - 例：「角質層（肌の一番外側の層）」
- 「でも簡単に言うと〜」「要するに〜」のブリッジ文を活用する

### 5-5. たまにはふざける

> **「真面目すぎ、たまには、ふざけようよ？もったいない」**

- 週1回程度、軽めのユーモア投稿を入れる
- 例：「成分表を読み始めてから、化粧品コーナーで1時間溶けるようになった」
- 例：「セラミド欠乏症（そんな病名はない）かもしれない人の特徴」
- 品質スコアのチェックを通過すれば自動承認対象（ユーモアは「自然さ」「感情移入」を押し上げる）

### 5-6. 読者が行動できるか

> **「その投稿を見て読者の方は行動できる？」**

- 各投稿に**1つの明確なアクション**を含める
  - 「成分表の〇〇を確認する」「今日から〇〇を変える」など
- 「参考にしてね」は禁止（行動が曖昧）。「〇〇してみて」で具体化する

| 項目 | 制約 |
|------|------|
| 文字数 | 500文字以内 |
| 日次上限 | 6件/日 |
| 投稿間隔 | 最低2時間 |
| 品質閾値 | 7.5以上 |
| 自動承認 | スコア8.5以上 |
